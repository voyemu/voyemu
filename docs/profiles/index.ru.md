# Профили

Каждая страница описывает один опубликованный [профиль](../how/profiles-machines.ru.md): какую прошивку он покрывает, его гостей, оригиналы, которые импортирует пользователь, и команды подготовки машины. Оригиналы не входят в Voyemu: пользователь импортирует их из своей прошивки.

Имя профиля называет линейку автомобиля, поколение Android, язык прошивки, её дату и версию. Каждый профиль показывает мультимедиа на двух экранах 1920×720 и рисует свой руль в [окне](../how/window.ru.md).

Подготовка любого профиля идёт по [общему порядку](../how/preparation.ru.md): `deps PROFILE`, затем `fetch` способом импорта профиля, затем `build`.

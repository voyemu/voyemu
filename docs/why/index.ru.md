# Почему так

Раздел фиксирует проектные решения Voyemu. Каждая страница — запись одного выбора: какие альтернативы рассматривались, почему победила одна из них и чего это стоит.

Запись нужна, когда решение неочевидно и его обоснование пригодится позже. Очевидному выбору здесь не место.

Каждая запись следует одному шаблону: **Решение → Контекст → Альтернативы → Аргумент → Последствия**.

# Участие в разработке

[English](CONTRIBUTING.md) | Русский

Voyemu принимает исправления, адаптации профилей и документацию. Штатные файлы прошивки, диски подготовленных машин и загрузки без пина не принимаются. Полные правила работы — в [AGENTS.md](AGENTS.md); порядок сообщения об уязвимостях описан в [SECURITY.ru.md](SECURITY.ru.md).

## Сборка

Voyemu собирается закреплённым набором инструментов Zig своего хоста, как описано на странице [сборки](docs/dev/build.ru.md). Zig, CMake и Ninja устанавливаются из `optionalTools` в `src/app/toolchain.json` с проверкой SHA-256 каждого архива. Каждому набору инструментов нужен новый каталог сборки.

| Хост | Файл набора инструментов |
| --- | --- |
| macOS arm64 | `src/dev/toolchains/zig-macos-arm64.cmake` |
| Windows x64, нативно или кросс-сборкой на Linux | `src/dev/toolchains/zig-windows-x64.cmake` |
| Linux x64, сборка и тесты | `src/dev/toolchains/zig-linux-x64.cmake` |

На Linux тесты хоста собирают и запускают следующие команды.

```sh
cmake -S src/app -B .local/build/linux -G Ninja -DCMAKE_TOOLCHAIN_FILE="$PWD/src/dev/toolchains/zig-linux-x64.cmake" -DBUILD_TESTING=ON
cmake --build .local/build/linux --parallel 2
ctest --test-dir .local/build/linux --output-on-failure
```

## Проверки перед коммитом

Включите хук один раз для рабочей копии. Он проверяет пробелы, форматирование исходников и Checkstyle закреплёнными инструментами. Хук читает подготовленные к коммиту данные и не меняет индекс и рабочие файлы.

```sh
git config --local core.hooksPath src/dev/git-hooks
```

Перед каждым коммитом запускается `lint-fix`: он применяет автоматические исправления clang-format, google-java-format и clang-tidy, затем запускает `lint` — те же проверки, что и CI. Каждое оставшееся замечание нужно исправить; подавить замечание можно только комментарием с причиной. Запускайте его в рабочем дереве только со своими изменениями, поскольку он форматирует все исходники. Каждой проверке нужны её закреплённые инструменты из `optionalTools` в `src/app/toolchain.json`; см. [проверки](docs/dev/checks.ru.md).

```sh
cmake --build .local/build/linux --target lint-fix
```

## Тесты

- Тесты C++ лежат рядом с кодом как `*.test.cpp`; тесты Java — в `src/prepare/test`.
- Тесты проверяют поведение: они никогда не читают исходники и не закрепляют хеши файлов репозитория; см. запись [тесты проверяют поведение](docs/why/behavior-tests.ru.md).
- Перед исправлением дефект воспроизводится падающим тестом, когда это практично.
- Каждый тест регистрируется через `voyemu_add_test` с метками и тайм-аутом; тесты, которым нужны оригиналы или настоящая графика, завершаются с кодом пропуска 77, если закреплённых входов нет; см. [тесты](docs/dev/tests.ru.md).
- Тесты хоста не заменяют приёмку гостей; изменение называет проверенные сценарии гостей и хост, на котором их проверяли.

## Пины

Версии зависимостей точные: последний релиз, если не записана причина выбрать другой. Каждая загрузка закреплена по URL и SHA-256 в `toolchain.json`, `qnx-host.json`, `dependencies.lock.json` или `component.json`, а образы Android и импорт с устройства — в `profile.json`. Файлы самого репозитория не закрепляются; см. [пины внешних входов](docs/why/pins.ru.md).

## Код

- Файлов и инструментов на Python в репозитории нет; см. [без Python](docs/why/no-python.ru.md).
- Новый код следует существующей архитектуре, именованию и стилю; каждый текстовый файл заканчивается ровно одним LF.
- Реализация одна для всех хостов, а различия хостов вынесены в бэкенды `src/app/os/`; см. запись [одна реализация](docs/why/single-implementation.ru.md).
- Об отказах код сообщает через `VoyemuError("CODE", "message")`; см. [коды ошибок](docs/why/error-codes.ru.md).

## Запросы на слияние

Для слияния запроса или отправки коммита напрямую в `main` нужна успешная проверка `Lint (Linux x64, Zig)` в GitHub Actions. Перед прямой отправкой запустите `ci` на ветке с тем же коммитом.

Один запрос на слияние — одна цель. Описание называет запущенные и пропущенные проверки и причины пропуска. Штатные файлы, диски машин, токены и другие секреты к запросу не прикладываются.
